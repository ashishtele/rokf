# rokf: R Interface to OKF Agent Memory

Provides an R-native interface to the OKF Agent Memory CLI (okf), a
Git-native persistent memory layer for AI agents built on the Open
Knowledge Format (OKF) v0.2. The package vendors pre-compiled binaries
for Linux, macOS (Intel/Apple Silicon), and Windows, enabling
zero-dependency installation. Use it to search, create, update,
validate, and relate knowledge concepts in your project's
version-controlled knowledge/ directory.
